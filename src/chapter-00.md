# 第零章 引言

在任意一门语言中, 入门材料所教授的内容, 与你经过多年实践经验后所掌握的知识之间的差距总是很大的. 随着时间的推移, 你会逐渐熟悉各种惯用语(idioms), 为核心概念建立更好的心智模型(mental models), 了解哪些设计和模式行之有效而哪些行不通, 并发现周边生态系统中实用的库和工具. 综合来看, 这些经验能让你用更少的时间写出更好的代码.

我写这本书, 是希望把我多年编写`Rust`代码的经验浓缩成一份易于消化的资源. `Rust for Rustaceans`接续了`The Rust Programming Language`("the Rust book")未竟之处, 无论你在哪里学到这门手艺, 它都非常适合任何想要超越基础的`Rust`程序员. 本书深入探讨了诸如不安全代码, `trait`系统, `no_std`代码和宏等概念. 它还涵盖了异步 I/O, 测试, 嵌入式开发和人体工学(ergonomic)API 设计等新领域. 我的目标是解释并揭开`Rust`这些更高级, 更强大特性的面纱, 让你能够构建出更快, 更符合人体工学且更健壮的应用程序.

## 本书内容

本书既可以作为指南, 也可以作为参考书. 各章基本相互独立, 因此你可以直接跳到特别感兴趣的主题(或当前正让你头疼的主题), 也可以从头到尾通读全书, 获得更全面的体验. 话虽如此, 我仍建议你先阅读第1章和第2章, 因为它们为后续章节以及你日常`Rust`开发中会遇到的许多主题奠定了基础. 下面是各章内容的简要介绍:

- 第1章, 基础, 对诸如变量, 内存, 所有权, 借用和生命周期等基本`Rust`概念给出了更深入, 更透彻的描述, 这些概念是你阅读本书其余部分所必须熟悉的.
- 第2章, 类型, 类似地, 对`Rust`中的类型和`trait`给出了更详尽的解释, 包括编译器如何对它们进行推理, 它们的特性和限制, 以及一些高级应用.
- 第3章, 设计接口, 介绍了如何设计直观, 灵活且不易被误用的 API, 包括关于如何命名的建议, 如何使用类型系统来强制 API 契约, 以及何时使用泛型而非`trait`对象.
- 第4章, 错误处理, 探讨了两类主要的错误(枚举的和不透明的), 每种错误在何时使用合适, 以及每种错误是如何被定义, 构造, 传播和处理的.
- 第5章, 项目结构, 聚焦于`Rust`项目中的非代码部分, 例如`Cargo`元数据和配置, `crate`特性以及版本管理.
- 第6章, 测试, 详细介绍了标准`Rust`测试工具(harness)的工作原理, 并展示了一些超越标准单元测试和集成测试的测试工具与技术, 例如模糊测试(fuzzing)和性能测试.
- 第7章, 宏, 涵盖了声明宏和过程宏, 包括它们如何编写, 有何用途, 以及它们的一些陷阱.
- 第8章, 异步编程, 先介绍了同步接口与异步接口的区别, 然后深入探讨了异步在`Rust`中是如何表示的, 既包括`Future`和`Pin`这样的底层, 也包括`async`和`await`这样的高层. 本章还解释了异步执行器(executor)的作用, 以及它如何让整个异步机制协同工作.
- 第9章, 不安全代码, 解释了`unsafe`关键字所解锁的强大能力, 以及伴随这些能力而来的重大责任. 你将了解不安全代码中的常见陷阱(gotchas), 以及可以用来降低不安全代码出错风险的工具和技巧.
- 第10章, 并发(和并行), 考察了并发在`Rust`中是如何表示的, 以及为什么在正确性和性能两方面都很难做好. 它涵盖了并发与异步之间的关系(相关但不相同), 当你更接近硬件时并发如何工作, 以及如何在编写正确的并发程序时保持清醒.
- 第11章, 外部函数接口, 教你如何让`Rust`与其他语言良好协作, 以及像`extern`关键字这样的 FFI 原语究竟做了什么.
- 第12章, 没有标准库的`Rust`, 全部内容都是关于在完整标准库不可用的情况下使用`Rust`, 例如在嵌入式设备或其他受限平台上, 在这些平台上你只能使用`core`和`alloc`模块所提供的功能.
- 第13章, `Rust`生态系统, 并不涉及某个特定的`Rust`主题, 而是旨在就`Rust`生态系统中的工作给出更广泛的指导. 它包含常见设计模式的描述, 关于跟上语言新增内容和最佳实践的建议, 关于实用工具的提示, 以及我多年来积累的, 在任何单一地方都无法找到的其他有用花絮.
